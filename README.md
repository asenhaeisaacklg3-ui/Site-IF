📊 Calculadora de Média e Faltas IFPI — Hackathon IA no CampusProjeto desenvolvido para o Hackathon IA no Campus do Curso Técnico em Informática para Internet (Integrado ao Ensino Médio) — IFPI Campus Paulistana.📌 Sobre o ProjetoDesafio Escolhido: Desafio nº 4 — Calculadora de Média e FaltasProblema Identificado: Os alunos do campus frequentemente encontram dificuldades para acompanhar seu desempenho acadêmico, sem saber com clareza quanto precisam tirar nas próximas avaliações para passar de ano ou se estão próximos do limite permitido de faltas.Público-Alvo: Alunos do IFPI Campus Paulistana.Link da Aplicação (GitHub Pages): https://github.com/asenhaeisaacklg3-ui⚙️ Funcionalidades (MVP)[x] Gestão por Disciplinas: Cadastro e inserção de notas por matéria.[x] Cálculo Automático de Média: Processamento imediato das notas informadas para exibir a média parcial/final.[x] Status Acadêmico: Exibição clara da situação do aluno (Aprovado, Em Recuperação ou Reprovado por Nota/Falta).[x] Controle de Frequência: Cálculo da porcentagem total de faltas com base no número de aulas ministradas.[x] Bônus (Simulador "Quanto Preciso Tirar"): Recurso interativo para simular qual nota mínima o aluno necessita na próxima avaliação para atingir a média de aprovação.🤖 Uso Crítico de Inteligência ArtificialA Inteligência Artificial foi utilizada como ferramenta auxiliar de desenvolvimento para planejamento, apoio na lógica de cálculo e estilização da interface. Todo o código gerado foi revisado, testado e adaptado pela equipe. Não foram inseridos dados pessoais reais de alunos ou servidores (todos os dados e nomes utilizados nos testes são fictícios).Registro de Prompts e Adaptações1. Prompt 1 — Estruturação do Form e Layout de DisciplinasPrompt Utilizado: "Crie um formulário HTML5 responsivo para inserção de notas e quantidade de faltas por disciplina, com campos para nota 1, nota 2, carga horária e total de faltas."O que foi aproveitado: A estrutura de inputs numéricos (type="number"), com restrições de valor mínimo e máximo (min="0", max="10").O que foi corrigido/adaptado: Ajustamos os atributos step="0.1" para permitir notas decimais e adicionamos mensagens de validação acessíveis para impedir envios com valores em branco.2. Prompt 2 — Lógica JS para Média, Faltas e SimulaçãoPrompt Utilizado: "Escreva uma função em JavaScript que receba um array de notas e faltas, calcule a média ponderada/aritmética, verifique a taxa de frequência % e retorne a nota necessária na próxima prova."O que foi aproveitado: A lógica matemática básica de média aritmética e a fórmula de porcentagem de faltas ($\text{Faltas \%} = \frac{\text{Faltas}}{\text{Aulas Totais}} \times 100$).O que foi corrigido/adaptado: A IA considerou a média de aprovação padrão como 6.0, mas adaptamos as regras de negócio para os critérios do IFPI (ex.: média de aprovação 7.0 e frequência mínima de 75%). Também ajustamos o arredondamento de decimais usando .toFixed(1).3. Prompt 3 — Estilização e Indicadores Visuais de StatusPrompt Utilizado: "Crie um arquivo CSS moderno para a calculadora com cards coloridos que alteram a cor de fundo (verde para aprovado, amarelo para recuperação e vermelho para reprovado/excesso de faltas)."O que foi aproveitado: Os estilos base para os cards de resultado e o design das badges de status.O que foi corrigido/adaptado: Ajustamos o esquema de cores para manter a identidade visual do IFPI e garantimos que os contrastes entre texto e fundo seguissem padrões de acessibilidade.🛠️ Tecnologias UtilizadasHTML5: Estrutura semântica e formulários de entrada de dados.CSS3: Estilização com Flexbox e Grid, variáveis de cores e efeitos visuais de status.JavaScript (ES6+): Cálculos matemáticos em tempo real, manipulação do DOM e simulações contextuais.Git & GitHub / GitHub Pages: Versionamento e hospedagem pública.👥 Integrantes da EquipeAires Vinicius — Desenvolvimento Front-End & Estilização CSS[Nome do Integrante 2] — Lógica de Negócio (JS) & Cálculos[Nome do Integrante 3] — Documentação, Testes & Publicação Git/Pages🚀 Como Executar o Projeto LocalmenteClone o repositório:git clone https://github.com/[seu-usuario]/calculadora-media-faltas-ifpi.git
